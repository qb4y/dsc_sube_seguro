# SubeSeguro Design System — Spec

**Date:** 2026-06-26  
**Approach:** Extract from prototype (Approach A)  
**Target:** claude.ai/design via `/design-sync` (shape: package)

---

## Goal

Build a React web design system extracted from the existing SubeSeguro prototype so the claude.ai/design agent can produce on-brand screens for the app. Components are self-contained inline-styled React, bundled as `window.SubeSeguroDS.*`.

## Components

### Primitives group

**Badge**  
Props: `verdict: 'green' | 'amber' | 'red'`, `label: string`  
Renders a pill with status color background and matching icon (ShieldCheck / ShieldAlert / ShieldX from lucide-react).

**Button**  
Props: `variant: 'primary' | 'ghost'`, `loading?: boolean`, `disabled?: boolean`, `children`, `onClick`  
Primary uses `colorBrand` bg + dark text. Ghost uses `colorSurfaceElevated` + light text. Loading shows ScanLine icon + "Revisando…".

**ChoiceButton**  
Props: `active: boolean`, `color: string`, `Icon: LucideIcon`, `label: string`, `onClick`  
Two-state toggle button used in pairs (Sí/No match confirmation). Active state uses `color + "22"` bg and matching border.

### Inputs group

**PlateInput**  
Props: `value: string`, `onChange: (v: string) => void`, `onSubmit: () => void`, `loading: boolean`  
Styled as a real Peruvian plate: blue "PE" sidebar, monospace input (26px, letter-spacing 0.14em). Loading shows a scan-line animation. Max 8 chars, auto-uppercased.

### Data Display group

**StatusRow**  
Props: `verdict: 'green' | 'amber' | 'red'`, `title: string`, `big: string`, `sub?: string`, `note?: string`  
Dark surface card with verdict icon + colored status label. Used for SOAT status display.

**VerdictCard**  
Props: `verdict: 'green' | 'amber' | 'red'`, `placa: string`  
Top-level verdict banner. Tinted bg matches verdict color. Shows large verdict label + plate number.

**VehicleCard**  
Props: `vehicle: { marca: string, modelo: string, color: string }`, `match: boolean | null`, `onMatch: (v: boolean) => void`  
Shows registered vehicle data and a ChoiceButton pair for physical match confirmation. Renders an alert row when `match === false`.

### Actions group

**ShareButton**  
Props: `shareUrl: string`, `shared: boolean`, `onClick: () => void`  
WhatsApp share link styled as a full-width button. Transitions from brand teal to surface after first share.

## Build Pipeline

**`package.json`**
```json
{
  "name": "subeseguro-ds",
  "version": "1.0.0",
  "main": "src/index.js",
  "peerDependencies": {
    "react": ">=18",
    "react-dom": ">=18",
    "lucide-react": ">=0.400"
  },
  "devDependencies": {
    "esbuild": "^0.21"
  }
}
```

**`build.mjs`** — esbuild bundles `src/index.js` as ESM + IIFE global `window.SubeSeguroDS`. Output: `dist/subeseguro-ds.js` (the converter reads from `dist/`).

**`styles.css`** — hand-authored file that `@import`s `_ds_bundle.css`. The `_ds_bundle.css` file is auto-generated by the `/design-sync` converter from the esbuild output — never edit it directly. Components use inline styles so this CSS is minimal; `styles.css` exists to satisfy the converter's requirement that a transitive `@import` closure exists for rendered designs.

## Preview Cards

Each `preview.html` renders on dark `#0E1116` background. Multi-state components show all states:
- `VerdictCard`: three side-by-side cards (green / amber / red)
- `StatusRow`: SOAT vigente, SOAT por vencer, SOAT vencido
- `PlateInput`: idle, loading, filled
- `Button`: primary, ghost, loading, disabled
- `ChoiceButton`: unselected pair, sí active, no active
- `VehicleCard`: match=null, match=true, match=false (alert)
- `ShareButton`: unshared, shared

## Conventions (agent usage)

Stored in `.design-sync/conventions.md`. Covers:
- All components need no provider/wrapper — inline styles, self-contained
- `lucide-react` icons used: `ShieldCheck`, `ShieldAlert`, `ShieldX`, `Share2`, `Car`, `ScanLine`, `ChevronRight`, `Check`, `X`, `Clock`
- Styling via `tokens` object — never raw hex
- Dark background (`colorBackground`) required on all screens
- Idiomatic snippet: plate lookup + verdict flow
